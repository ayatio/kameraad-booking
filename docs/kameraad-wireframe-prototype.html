Privacy & Data Sovereignty
Principles:
• Own database — no third-party booking platform stores customer data
• GDPR Article 17 "Right to Erasure" — permanent deletion capability
• No analytics tracking beyond server logs
• All data hosted on Railway EU region
• Email processing via Resend (GDPR-compliant, data processing agreement)
• No cookies beyond essential session management
• Admin has full control: can export, delete, or modify any record
• Cancellation of Calendly eliminates third-party data dependency
Core differentiator: complete data sovereignty. Client owns 100% of customer data with no vendor lock-in.
Secure Deletion Architecture
Admin triggers "Delete Customer" →
  1. DELETE FROM bookings WHERE customer_id = ?
  2. DELETE FROM email_log WHERE customer_id = ?
  3. DELETE FROM customers WHERE id = ?
  4. Confirmation: "All records permanently removed"

  → No soft delete. No recycle bin. No recovery.
  → Audit log records deletion event (not deleted data).
Hard delete cascade. Meets client requirement for irrecoverable purge.
